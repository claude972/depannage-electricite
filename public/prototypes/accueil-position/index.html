Voir l’assistance
Quel sera le prix du dépannage ?

La fourchette affichée est indicative. Après le diagnostic, l’artisan présente un devis avec le coût des travaux. Si le périmètre change ensuite, un devis mis à jour est soumis à votre accord.

Que se passe-t-il après ma demande ?

La recherche d’un électricien tient compte de votre commune et des disponibilités. Le créneau souhaité devient un rendez-vous une fois confirmé dans votre dossier.

Dois-je créer un compte pour suivre ma demande ?

Le compte est facultatif. Pour retrouver vos interventions, vous pouvez vérifier le numéro de téléphone associé à la demande. Voir le parcours de suivi.

Comment se passe le règlement ?

Le règlement passe par la plateforme. Si vous choisissez une empreinte bancaire, elle réserve le montant annoncé sans débit immédiat. Le règlement final intervient après les travaux sur la base du devis accepté.

À qui m’adresser après les travaux ?

Depuis le dossier de l’intervention, vous pouvez retrouver le devis et les justificatifs disponibles, ou contacter l’assistance si un problème persiste.
