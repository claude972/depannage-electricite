# D11 — quitter la carte après redimensionnement

Correspond au défaut W2 découvert par Claude sur le Web à 390 px. Leaflet 1.9.4 peut émettre `moveend` 200 ms après une invalidation de taille. Si la carte est détruite entre-temps, notre callback appelait `getCenter()` après la suppression du panneau, provoquant `Cannot read properties of undefined (reading '_leaflet_pos')`.

Les callbacks de déplacement, redimensionnement et chargement des tuiles vérifient maintenant que leur instance est encore active. Aucun changement de localisation, de service cartographique ou de permission.

Le test Chromium charge le vrai composant React et la vraie version installée de Leaflet. Il déclenche le redimensionnement puis quitte l’étape avant le callback différé. Le test échoue avant correction avec l’erreur exacte et réussit après correction à 390 et 1280 px, sans callback d’adresse ancien. Une carte remontée reste déplaçable. Les tuiles externes sont interceptées ; le test n’utilise aucune adresse réelle.
