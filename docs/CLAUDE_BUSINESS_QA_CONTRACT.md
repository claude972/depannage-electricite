## 1. Commandes

```
node scripts/qa-business/run.mjs --base-url <origin> --sha <40 hex> --project <ref> --credentials <json>
                                 [--suite docs|b2b|all] [--app-dir <checkout>] [--out <dir hors dépôt>]

```

- `--suite` : `docs` (lot 015), `b2b` (lot 017), `all` (défaut : docs puis b2b). Suites inconnues ou dupliquées → refus `2`.
- `--dry-run` : préflight complet **sans aucune requête réseau** (ni Supabase, ni application), impression du plan (fixtures, ordre de nettoyage, sorties, codes) et sortie `0`. Les credentials sont facultatifs en dry-run (forme validée s’ils sont fournis).
- `--cleanup-manifest` : rejoue uniquement le nettoyage d’un manifeste conservé (second signal, nettoyage incomplet, issue inconnue) ; refuse un manifeste d’un autre projet.
- Codes de sortie (identiques au harnais existant) : `0` aucun FAIL ; `1` au moins un FAIL ou un FATAL ; `2` refus de préflight ; `3` nettoyage incomplet ou **issue inconnue** (voir §4) ; `130` interruption après nettoyage (second signal : nettoyage abandonné, manifeste conservé, `130`).
